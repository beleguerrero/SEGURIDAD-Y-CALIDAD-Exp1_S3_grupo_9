
# Exp1_S3_belen_guerrero
Actividad Sumativa 1: Securitización de aplicación web

## Tecnologías

- Java
- Spring Boot
- Thymeleaf
- Spring Security
- Tailwind CSS

## Ejecución

Ejecutar el proyecto desde el IDE o mediante Maven:

```bash
mvn spring-boot:run
```

La aplicación estará disponible en:

http://localhost:8081
